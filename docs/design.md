# v0.1 设计与实施计划

已确认方向：README 三图生成器。服务开源维护者，不做通用画布，不提供托管 AI。

交付：overview / architecture / quickstart 三种 SVG，明暗各一套；JSON 可编辑源；离线 HTML 预览；README 嵌入片段；来源证据报告；独立可携带 Skill。

边界：Agent 或人整理 JSON，渲染器不调用模型、不执行项目命令、不自动推断架构。证据校验只证明路径和行范围存在，不证明语义正确。架构支持最多六个节点的有向无环图，需先抽象循环。

实现顺序：测试失败 → 校验器与确定性排版 → CLI 和离线预览 → 三类自建示例 → 中英文文档和视觉验收 → 打包。Node.js 22+、零第三方运行依赖。

输出安全：只新建不存在的输出目录，不覆盖已有目录；输入有大小/字段长度/节点数量限制；证据仅允许项目根目录内普通文本；拒绝逃逸路径及符号链接逃逸；所有 SVG/HTML 文本转义。发布 GitHub、授权登录和获得 Star 不属于本地生成步骤。
